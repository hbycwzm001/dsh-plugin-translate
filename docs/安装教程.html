DSH PLUGIN · INSTALL GUIDE

按国家翻译
安装与使用（从零到能翻）

装 DSH → 装插件 → 填一个 key → 顶栏多出「翻译」。全程约 3 分钟，不用命令行（市场安装法）。
3 步安装 依赖只有 2 个 249 国 DeepSeek / Google 双引擎

1先看清：装完是什么样

对话· 轨迹· 上下文· 队列→ 翻译

就多这一个标签。点开是：目标国家 + 翻译引擎 + 语气 + 输入框 + 「翻译」按钮。没有别的配置要动。

2三步装好（推荐：市场安装）

  1. DSH → 插件 → 发现 → 添加索引源把下面这一行地址粘进去，确定：
    https://hbycwzm001.github.io/dsh-plugin-translate/market/index.json
  2. 在插件市场里搜「Translate」或「按国家翻译」点安装。装完会显示已启用（不需要重启 DSH）。
  3. 回到对话页，按 Ctrl + R 刷新顶栏出现「翻译」标签，就能用了。

3另外两种装法（市场装不上时用）

git 直装

有命令行环境时最快，一条命令：

dsh plugin add git+https://github.com/hbycwzm001/dsh-plugin-translate.git

本地目录安装

离线场景：下载仓库 zip → 解压 → 插件 → 从本地目录安装 → 选解压出来的根目录（里面有 package.json 那一层）。

4依赖：只有两件

东西必须?说明 / 哪里来
DSH Desktop ≥ 0.2.2-rc.1必须宿主要先装着、能正常打开对话。
本插件 dsh-plugin-translate必须就是本文教你装的这个，约 60 KB。
DeepSeek API Key强烈建议放在 ~/.dsh/.credentials.yaml 里叫 DEEPSEEK_API_KEY；如果 DSH 本身能正常聊天，通常已经有了。没有也能在面板里临时填。
能翻墙的客户端可选只有你切到 Google 引擎 才需要；用 DeepSeek 引擎完全不用。
Python / Node / 模型文件不需要这个插件没有本地模型、不下载大文件，纯接口调用。
一句话：DSH 能聊天 = key 已经有了 = 插件装完就能直接翻。不用另外买服务、不用下几百兆。

5装完第一次用（4 步）

  1. 点顶栏「翻译」对话区换成翻译面板。
  2. 选目标国家常用国家有快捷按钮（美国 / 日本 / 墨西哥 / 巴西 / 德国 / 法国）；其他 240 多个点开列表或用搜索框输国名、语言、货币代码。
  3. 粘中文 → 点「翻译」也可以按 Ctrl + Enter，一般 1～3 秒出结果。
  4. 复制 / 反向翻译结果卡上「⧉ 复制」直接拿走；拿不准就点「⇄ 反向翻译」翻回中文自检。

6两个开关要知道

翻译引擎

DeepSeek（默认，推荐）：按国家做本地化，翻成当地人真正会说的话。
Google：逐句直译，只用来对照，需要代理。

显示 / 隐藏「翻译」标签

插件设置里有一个开关。关掉只是隐藏入口，翻译能力（Agent 工具）照常可用；想再看到就重新打开。

7装完没出现「翻译」标签？按顺序查

现象怎么办
插件列表里没有它索引源没加成功。回「插件 → 发现 → 添加索引源」重新粘一次地址；粘完列表里应能看到 Country Translator。
装上了但没标签没刷新。在 DSH 里按 Ctrl + R；或退出重开 DSH。
标签在，但下拉是空的还是缓存问题：Ctrl + R 硬刷一次。插件内置了 249 国表，正常不会空。
一点翻译就报 key 无效面板会弹出输入框，粘一个有效 key 点「保存并重试」。key 只存在本次会话内存里，不写盘。
选 Google 时报 429 / 超时谷歌免费接口对出口 IP 限流。换节点，或直接用 DeepSeek 引擎。

8把插件发给别人

你只需要发两条东西给对方：

① 索引源地址（装插件用）

https://hbycwzm001.github.io/dsh-plugin-translate/market/index.json

② 这份说明图（就是你正在看的这张）

对方流程：装 DSH → 加索引源 → 搜 Translate → 安装 → Ctrl+R → 用。整个过程不需要你远程帮忙。

提醒对方两件事
① 这个插件本身不含任何账号密码，也不需要你给他 key —— 用的是他自己 DSH 里的 DeepSeek key。
② 谷歌引擎只是可选对照，默认的 DeepSeek 引擎在墙内直接能用，不需要任何代理。
一句话：加一行索引源 → 市场里搜 Translate → 装 → Ctrl+R → 点「翻译」选国家粘文字。依赖只有 DSH 和一个 DeepSeek key，别的都不用装。
