1它长在哪

装好插件后，DSH 对话窗口上方会多一个「翻译」标签，和「对话 / 轨迹 / 上下文 / 队列」并排。

对话· 轨迹· 上下文· 队列→ 翻译（新增）

点开就是一个面板：目标国家 + 翻译引擎 + 语气 + 输入框 + 按钮。没有第二步配置，不用开命令行。

2三步翻译

  1. 点顶栏「翻译」对话区换成翻译面板，上次的输入和结果还在。
  2. 选目标国家常用国家有快捷按钮（美国 / 日本 / 墨西哥 / 巴西 / 德国 / 法国）；其他 240 多个用搜索框输入国名、语言或货币代码。
  3. 粘文字 → 点「翻译」也可以按 Ctrl + Enter；通常 1～3 秒出结果。

3选国家：两种方式，249 个

预设 + 下拉

点开就是一个大列表，鼠标选。每行显示 国名 · 语言 · 货币，一眼能看出翻成哪种话、花的是哪种钱。

直接搜索

输入框里敲国家名、语言名、货币代码都行：巴西、葡萄牙、BRL、ar-SA 都能命中。

同一个语言在不同国家是两套说法，所以列表按“国家”而不是“语言”排：美国 en-US英国 en-GB墨西哥 es-MX西班牙 es-ES巴西 pt-BR葡萄牙 pt-PT

4翻译引擎：两套，选一个

引擎效果什么时候用
DeepSeek
推荐		 按目标国家做本地化：用当地惯用语、当地语气、当地数字格式。同一个词，美国说法和墨西哥说法会不一样。 发给客户、发帖、报价单 —— 要“像当地人写的”。

5语气：四档，影响用词

口语化商务

像销售在微信上跟客户聊，自然、不生硬。默认。

正式商务

报价、合同、正式邮件。用词克制，不缩略。

日常口语

朋友之间说话，带当地俚语，最“接地气”。

客服友好

售后、答疑。语气软，先共情再给方案。

6实时汇率：一行算完

怎么用
左边选源国家（默认 中国 · CNY），输入金额，右边选目标国家，第二列自动出现该国货币金额。
看到的样子
中国·中文·CNY　[10] CNY →　美国·英语·USD　$1.49　1 CNY ≈ 0.1494 USD
更新时间
每天更新一次（源时间 00:02 UTC = 北京 08:02）。点 ↻ 刷新 可强制重取。
口径
中间价（市场价），不是银行柜台现钞牌价；做正式报价请以银行牌价为准。

8它和普通翻译的区别（同一句话）

原文：这台东风勇士 EQ2050 是 3.2L 涡轮增压柴油四驱，军规底盘，涉水 1.2 米，现车在洛杉矶仓，25 万人民币起。

目标国家译文（节选）
美国 en-USThis Dongfeng Warrior EQ2050 runs a 3.2L turbo diesel with four-wheel drive… It's in stock at our LA warehouse, starting at ¥250,000 RMB.
墨西哥 es-MXEsta Dongfeng Warrior EQ2050 trae motor 3.2L turbodiésel, tracción 4x4… Unidad disponible… despacho aduanal…
沙特 ar-SAهذي الـ EQ2050 بمحرك ديزل تيربو… متوفرة الحين…
用海湾口语 هذي / الحين（书面语是 هذه / الآن）
巴西 pt-BREssa Dongfeng Warrior EQ2050 é 3.2L turbo diesel… passa por até 1,2 m de água… a partir de ¥ 250.000

差别在细节：墨西哥用 trae motor（不是 tiene）、沙特用海湾口语 هذي / الحين（不是 هذه / الآن）、巴西小数点写成 1,2。这些正是“当地人一看就懂”的地方。

9常见问题

现象怎么处理
国家下拉是空的插件装好后没刷新。按 Ctrl + R 重载界面；仍空就是插件没加载成功，去「插件」页看是否启用。
翻译失败：api key 无效面板会弹输入框，填一个有效的 DeepSeek key 后点「保存并重试」；key 只在本次会话内存里，不落盘。
谷歌引擎报 429 / 超时谷歌免费接口对出口 IP 限流。换节点、或直接用 DeepSeek 引擎（更稳，也更适合本地化）。
汇率和我印象里不一样插件用的是中间价，且每天更新一次。以 api.frankfurter.app 等第三方交叉核对，误差 1% 内属正常。
只想要入口不占地方插件设置里有「在对话顶部显示「翻译」标签」开关，关掉只隐藏入口，翻译能力和 Agent 工具照常可用。
两条使用提醒
① 翻译结果建议用「反向翻译」自检一次再发客户 —— 尤其是金额、型号、法规这几类不容出错的内容。
② 汇率是中间价、每天一更，只适合参考和初步报价；正式合同请用银行当日牌价。
一句话：选国家 → 粘文字 → 点翻译。要“像当地人说的话”用 DeepSeek；只要看懂意思用 Google。价格拿不准，就在中间那行汇率里算一下。
